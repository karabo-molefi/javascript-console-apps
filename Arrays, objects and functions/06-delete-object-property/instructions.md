# Task

Write a JavaScript program to delete the *age* property from the following object. Also print the object before or after deleting the property.

```javascript
let student = {
    name: "David",
    surname: "Ray",
    studentNumber: 10972,
    age: 22
};
```

## Expected Output

Printed after deleting the property:

```
{ name: 'David', surname: 'Ray', studentNumber: 10972 }
```
