# Task

Write a JavaScript program to list the properties of the given JavaScript object:

```javascript
let student = {
    name: "David",
    surname: "Ray",
    studentNumber: 10972
};
```

## Expected Output

No sample output is given. Example:

```
name: David
surname: Ray
studentNumber: 10972
```
