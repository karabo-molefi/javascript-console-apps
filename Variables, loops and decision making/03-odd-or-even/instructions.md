# Task

Write a JavaScript loop that will iterate from 0 to 15. For each iteration, it will check if the current number is odd or even, and display a message to the console.

## Expected Output

Example (wording of the message is up to you):

```
0 is even
1 is odd
2 is even
3 is odd
...
14 is even
15 is odd
```
