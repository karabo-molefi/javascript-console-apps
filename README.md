# JavaScript Console Apps

A collection of mini JavaScript console app projects for practicing core concepts like arrays, objects, and array methods (`map`, `filter`, `reduce`, `sort`).

## Prerequisites
- [Node.js](https://nodejs.org) installed on your computer

## How to use this repo
1. Open a project folder, e.g. `Library Record System`.
2. Read the `instructions.md` file.
3. Try solving the problem on your own.
4. Check `script.js` for the solution.
5. Run the project with `node script.js`.
