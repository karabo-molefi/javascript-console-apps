# Task

Create a program to terminate an infinite loop. Do not use the `break` statement (or `return`). The loop must be terminated if it has run *n* amount of times, where n is an argument for a function.

*Requirement: use literal values in code.*

## Expected Output

For n = 5, the loop body runs exactly 5 times and then stops. Example:

```
Iteration 1
Iteration 2
Iteration 3
Iteration 4
Iteration 5
Loop terminated
```
