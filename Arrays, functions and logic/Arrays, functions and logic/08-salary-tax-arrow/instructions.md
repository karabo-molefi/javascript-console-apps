# Task

Create a JavaScript application that uses an arrow function to calculate the tax of a given salary. Below are the tax brackets:

| Salary | Tax |
|---|---|
| salary < 8000 | 0.15 |
| 8000 < salary < 12000 | 0.20 |
| Salary > 12000 | 0.25 |

Utilize if-else decision constructs in the implementation of your program. The application must be able to log the following in console if a salary of 15000 is entered:

## Expected Output

```
Your tax is 3750
```
