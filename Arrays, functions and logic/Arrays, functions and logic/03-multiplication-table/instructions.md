# Task

Write a program that draws an n * m multiplication table, where n and m are arguments for a function.

*Requirement: use literal values in code.*

## Expected Output

For n = 3 and m = 4 (n rows, m columns):

```
1	2	3	4
2	4	6	8
3	6	9	12
```
