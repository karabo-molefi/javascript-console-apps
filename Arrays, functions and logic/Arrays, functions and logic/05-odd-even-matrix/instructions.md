# Task

Given the following representation of a matrix, write a program that selects odd and even numbers. The program must make use of a function that takes three arguments: the matrix array, another array called `odds`, and another array called `evens`. Save the odd numbers and the even numbers in the respective array. Finally, print the contents of the arrays in the console.

```
19, 23, 29
23, 15,  7
11, 13, 17
```

*Requirement: use literal values in code.*

## Expected Output

Every number in this matrix is odd, so `evens` ends up empty:

```
Odds: 19, 23, 29, 23, 15, 7, 11, 13, 17
Evens: (empty)
```
