# Task

Write a login application that allows the user to enter login details – 3 attempts.

## Expected Output

The output depends on what the user enters. Examples:

```
Correct details within 3 attempts:
Correct username and password! You are now logged in!

Wrong details on all 3 attempts:
Wrong username or password try again.
Wrong username or password try again.
Wrong username or password try again.
Three wrong attempts, goodbye!
```
