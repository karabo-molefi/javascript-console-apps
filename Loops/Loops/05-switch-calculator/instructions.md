# Task

Write a program to simulate a simple calculator using the switch statement that performs arithmetic operations like addition, subtraction, multiplication, and division only on integers. This program takes an arithmetic operator +, -, *, / and two operands from the user. Then, it performs the calculation on the two operands depending upon the operator entered by the user.

## Expected Output

The output depends on the input. Examples:

```
6 + 3  ->  9
6 - 3  ->  3
6 * 3  ->  18
8 / 2  ->  4
6 % 3  ->  Invalid
```
